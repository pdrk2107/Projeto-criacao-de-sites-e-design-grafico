# VASHOP – Loja virtual

E-commerce fictício de produtos do Vasco da Gama (projeto acadêmico de Criação de Sites).

## Funcionalidades
Login simulado, categorias, busca, filtro/ordenação, detalhe do produto, carrinho (quantidade, remover, cupom `VASCO10`, frete), checkout com validação, pagamento por débito, crédito (parcelamento até 6x) e PIX, confirmação de compra. Carrinho salvo no `localStorage`.

## Como executar
Abra `index.html` no navegador. Nenhuma instalação necessária.

## Estrutura
`index.html` · `css/style.css` · `js/script.js`
